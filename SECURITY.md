# Security Policy

## Organization Scope

This security policy applies to all repositories under the playerhub-pipeline organization.

## Supported Versions

Only the latest commit on the main branch of active repositories receives security updates and patches.

## Reporting a Vulnerability

The PlayerHub engineering team takes security vulnerabilities seriously. If you discover a vulnerability or security flaw in any PlayerHub service, please report it privately:

- **Security Contact**: omarmo.abdelsalam@gmail.com
- **Lead Maintainer**: @omarMohamedo-o

### Reporting Guidelines
1. Never open a public issue or discussion describing an unresolved security vulnerability.
2. Provide a reproduction scenario, impacted components, and potential impact.
3. We will acknowledge your report within 48 hours and provide regular status updates during remediation.
4. Security advisories will be published only after a fix is merged to main.
