# Getting Support for PlayerHub Pipeline

Welcome to the PlayerHub Pipeline support guide.

---

## 💬 Where to Get Help

- **GitHub Discussions:** Use [Discussions](https://github.com/playerhub-pipeline/demo-repository/discussions) for general architecture questions, Q&A, and technical proposals.
- **Issue Tracker:** For verified bugs, regressions, or infrastructure outages, open an issue using the appropriate template in the relevant repository.
- **Security Vulnerabilities:** Do NOT create public issues for sensitive security reports. Refer to [SECURITY.md](SECURITY.md) for coordinated disclosure instructions.
- **Maintainer Contact:** Reach out directly to `@omarMohamedo-o` for critical production escalation.
